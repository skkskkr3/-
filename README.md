# 知序：学习通学习助手 MVP

一个可在 Windows 本机试用的学生学习工作台：学习通和教务系统分别首次授权登录后，打开看板会自动尝试刷新课程任务、本学期课表及已发布成绩；官网会话过期时提示重新登录。作业草稿由学生主动启动并审核；教务数据不发送给 AI。

在 Windows 桌面双击 `Start-Zhixu.cmd`（推荐）或 `启动知序.cmd`，保持弹出的命令窗口开启；服务就绪后会自动打开本地网页。登录时的学习通浏览器窗口也会出现在同一桌面。或者在你自己打开的 PowerShell 中运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\run.ps1
```

### 发给同学测试

不能只发送 `.cmd` 文件：它只是入口，还依赖同目录里的 `run.ps1`、`launcher.py`、`app.py`、`static` 和其他项目文件。请先排除自己的 `.venv`、`data`、`.browsers` 文件夹，再把整个项目文件夹压缩成 ZIP。让同学完整解压 ZIP 后，双击纯英文名称的 `Start-Zhixu.cmd`；不要直接在聊天软件的压缩包预览中运行。

新的 CMD 入口使用 Windows CRLF 换行和纯 ASCII 内容，可避开部分聊天软件、压缩工具和中文编码造成的兼容问题。如果启动失败，窗口会保留错误码，截图即可排查。

首次运行需要联网安装依赖，并使用电脑上已安装的 Microsoft Edge 弹出平台官网登录窗口。学生本人在官网完成登录；知序不另设密码，也不会读取日常 Edge 资料中的保存密码或登录状态。当前账号已验证可只读导入学习通任务、教务课表和成绩，但官网改版后仍可能需要更新适配器。当前版本不会自动提交作业，也不会修改教务数据。
